# Bitway Earn

Bitway Earn is the smart contract implementation of the Bitway Earn on-chain yield product — a DeTradFi vault system deployed on BNB Chain that enables users to deposit stable assets (e.g., USDT/USDC) and earn optimized, market-neutral returns via institutional-grade strategies. Users receive on-chain vault tokens representing their share of the strategy and accumulated yield, while Bitway Earn leverages a hybrid model of on-chain transparency and secure off-chain execution for efficient yield generation.
